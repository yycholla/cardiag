2What the car offers

3Car profile

The car does not report its engine size or transmission. The air flow check needs the first; the Drive page words its findings by the second.

4Idle baseline

Park with the engine warm, air conditioning and lights off, and leave it idling. After a minute the averages are kept as this car's own healthy bands.

5Gear learning

Drive gently and hold a steady speed for a few seconds in each gear, starting from first. A light foot keeps the clutches locked, which is what the gear lines need. Then learn from that drive, live or from a recording of it.

6Values only this maker has

Modules keep figures beyond the standard set: a dual-clutch gearbox knows its own clutch slip, its clutch temperature and the gear it wants. Makers do not publish where these are kept, so each one is an identifier to find and a rule for turning its bytes into a number, checked against the car. Reading them is a read, like everything else cardiag sends.

cardiag reads these on 11-bit CAN networks only so far, and this car is on another kind.

Find what a module answers

Asks the module chosen above for a run of identifiers and lists the ones it has, with their bytes. Do it parked, with the engine running. Then change one thing (select a gear, let the car warm up), scan again, and see which bytes moved: that is how a value is recognised.

Capture everything through a drive

A discovery run keeps the raw bytes of every identifier the module answers, read in turn for as long as you drive, beside engine speed, road speed and the pedal. Afterwards it ranks which bytes moved with the gear, with clutch slip, with heat and so on. Start it parked: it first asks through the range above, which takes a few minutes for a wide one, then keeps reading what answered. While it runs, the Live tab shows only the few values it needs.

Ready to use

Configuration

Settings kept in the car's modules, decoded from their configuration blocks. Changing a value here only drafts it: the page shows the block it would make, and nothing is sent to the car.

Data source

A simulated car shows made-up data, for trying the app without a car. The app goes back to the real car whenever it restarts.

Wi-Fi

Home network

Save a Wi-Fi network to put this box on it when you ask, for example to install updates at home. The hotspot still starts every time the box is switched on.

Travelling hotspot

Save your phone's or tablet's hotspot to give this box a way out to the internet on the road. The box joins it by itself whenever it is in range, and keeps looking for it while it is away.

Polling

How often the watched values are read. The car sets the ceiling: each value takes a moment to answer, so watching fewer values gives more updates a second.

Central server

Finished recordings are sent to another copy of cardiag, started with --accept-uploads, whenever this box can reach it. There is no login, so use an address on a private network such as Tailscale.
