2What the car offers

3Car profile

The car does not report its engine size or transmission. The air flow check needs the first; the Drive page words its findings by the second.

4Idle baseline

Park with the engine warm, air conditioning and lights off, and leave it idling. After a minute the averages are kept as this car's own healthy bands.

5Gear learning

Drive gently and hold a steady speed for a few seconds in each gear, starting from first. A light foot keeps the clutches locked, which is what the gear lines need. Then learn from that drive, live or from a recording of it.

Ready to use

Data source

A simulated car shows made-up data, for trying the app without a car. The app goes back to the real car whenever it restarts.

Wi-Fi

Home network

Save a Wi-Fi network to put this box on it when you ask, for example to install updates at home. The hotspot still starts every time the box is switched on.

Travelling hotspot

Save your phone's or tablet's hotspot to give this box a way out to the internet on the road. The box joins it by itself whenever it is in range, and keeps looking for it while it is away.

Central server

Finished recordings are sent to another copy of cardiag, started with --accept-uploads, whenever this box can reach it. There is no login, so use an address on a private network such as Tailscale.
